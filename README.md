# jurimetria_aved_stf

Análise empírica de decisões do STF sobre desinformação e atos antidemocráticos (8/1).
Pipeline reprodutível em Python: extração de PDFs, limpeza, aderência temática,
ranqueamento (MCDA/WSM), amostragem estratificada, nuvem de palavras e heatmap PPMI condicionado.

Autoria: **Cibele Alexandre Uchoa**.
